How To Use This Planner
  1. Print pages at 100% scale ("Actual Size" / no "fit to page" scaling) for accurate box sizes.
  2. Best on standard 20lb+ printer paper; card stock recommended for the cover.
  3. Reprint any page as many times as you like — this is a reusable template.
  4. Prefer digital? Import the PDF into GoodNotes, Notability, or OneNote and use it on a tablet.
  5. Start with the Monthly Budget Tracker, then set one goal on page 3 to build momentum.
